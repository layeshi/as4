状态：方案已审定；0.3.0 已实现（客户端改版与服务端 S1–S3），待你审阅与真机验收，尚未上传、提交或部署；0.3.1 未开始。基线：GitHub main `37e0016`（小游戏 0.2.1，`wechat/minigame/`）。样稿画布：https://claude.ai/artifact/Q686BjPdraYMRrYqp18hUZ （10 张，使用 2026-10-12 线上城 p6-20261011 第 8 日的真实数据；「居民管理」页的用量、模型名和家书是示例）。

- 宋体子集：经你同意下载 google/fonts 的 `NotoSerifSC[wght].ttf`（哈希与 GitHub 记录一致，SIL OFL 1.1，未声明保留字体名），用 HarfBuzz 固定为粗体并取界面写定的 520 个字，得到 `wechat/minigame/fonts/HeirsSerif.ttf`（175 KiB）；源字体不进仓库。

## 2. 现状问题（证据）

- 样式：只有文字段落和通栏长方块两种元素，按钮、输入框、勾选框、列表项外观相同；按钮底色 `#172326` 与背景 `#10191c` 的对比为 1.11:1。档案馆五个分栏是竖排通栏按钮，先占约 290px。底部导航只有文字，按固定偏移（`width/8 - 23`）摆放，二字和三字标签对不齐。地图是半径 3–5px 的圆点和截成 7 字的 10px 标签，标签互压、点按区（32×34）重叠。
- 配色：墨绿黑配金色，与标志（夜蓝月白）和网站（深蓝配蓝）不是一家；金色同时表示主按钮、提示、选中和地图上有人。
- 交互：没有惯性滚动、滚动条和下拉刷新；每次 touchmove 都重建全部内容，并用 `measureText` 逐字重新排版。错误提示是滚动内容的第一块，翻下去就看不见；按下无反馈。
- 匿名几乎读不到文字：匿名请求线上 `/api/wechat/public/state`，865 段文字中 561 段为「内容审核中」，5 个居民名、15 个地点名全被遮，包括「港口」这类系统名字。原因：`src/wechat/projection.js` 只在两小时内微信登录过的请求里送审，结果只存内存 24 小时。
- 事件名：最近 60 条事件中 33 条的类型（explore、gather、give、rule_op、material_regrowth、day）不在小游戏的对照表里，显示成「城市事件 · explore」。网站 `public/i18n.js` 已有完整中文句式与分类。
- 未用上的后端能力：公共角色（state.publicRoles）、天象、管理页的今日用量与每日上限（`GET /api/wechat/residents/:id` 已返回 `overview.usedToday/dailyCap`）、调整上限（`POST …/cap`）、居民统计。模型配置要在手机上手打完整 HTTPS 地址，且写死了 `maxTokens: 1200`、`timeoutMs: 45000`。

### 3.2 字号与间距

标题 26（宋体）、小节 18–21（宋体）、卡片标题 16、正文 16/行高 26（现为 14/23）、动作句 14/22、说明 13、标签 12。左右边距 16，卡片内边距 14–16，间距取 4 的倍数。圆角：卡片 16–18、按钮 14–16、标签 10–12、底部弹出卡片 22。可点区域不小于 44×44。

### 3.3 组件

主按钮（月白实心）、次按钮（描边）、文字按钮；状态标签；分段控件；搜索框；列表行；统计块；进度条；发言气泡；动作行（线性图标 + 句子）；按刻分组标题；日终摘要卡；底部弹出卡片；全屏编辑页；顶部轻提示；加载骨架；空状态。图标统一为 24px 线性图标（描边 1.8），用 Canvas 路径绘制。不用模糊、大面积阴影和渐变铺底。

### 3.4 头像

居民：审核通过的上传头像裁成圆形，外圈月白半透明描边；否则显示首字印章，底色由居民 id 稳定映射到一组低饱和色。公共角色：方形印章，沿用 `public/roles/*.svg` 的色相与字，在 Canvas 里直接绘制。地图上用 20–24px 的小头像，列表 44–46px，个人页 60–72px。

## 4. 交互

- 布局：顶栏按 `wx.getMenuButtonBoundingClientRect()` 避让右上角胶囊；底部导航高 49 + 安全区。
- 滚动：惯性、回弹、滚动条、下拉刷新。按下变暗；轻震（`wx.vibrateShort({type:'light'})`，设置里可关）。成功与错误用顶部轻提示，2.5 秒消失；表单错误同时贴在对应字段下。
- 地图：点地点弹出底部卡片（完好度、出能或用途、此处居民与公共角色、近 7 日走势、入口）；地图卡右下角有「定位到我的居民」和「全屏」；全屏地图支持双指缩放和拖动（第二批）。
- 输入：仍用 `wx.showKeyboard`，加 `wx.onKeyboardInput` 实时更新预览和字数；家书和灵魂用全屏编辑页。
- 刷新：事件仍取最近窗口（`recent=1`，以免漏掉延迟公开的旧事件）；拿到新事件或跨刻（`world.nextTickAt`）时才重取城市状态；进入后台停止；顶部显示「距下一刻」倒计时。
- 性能：文字排版按（文本、宽度、字体）缓存；地图画在离屏画布，数据或缩放变了才重画；只在滚动惯性和动画期间逐帧绘制。

## 5. 各页

**启动**：标志插画、「后人纪 / 词元本位」、16+ 标识、四行排版的健康游戏忠告、AI 模拟说明、「进入城市」、版本与隐私说明入口。点按钮前不发网络请求、不显示导航（保持现有测试约束）。

**观测**：城名、实况点、第几日第几刻、倒计时；地图卡（街道、城墙、海岸、地点四类标记、居民头像、刚有动静的地点用光圈）；统计块（在世居民、公库、源井）；「此刻」：
- 按刻分组；事件用网站的中文句式模板，构建时从 `public/i18n.js` 同步到小游戏；
- 筛选沿用网站 `public/i18n.js` 的八类事件分类（言语、经济、政治、生死、知识与铭刻、建造与环境、天时、幕后），做成可横向滑动的标签，「幕后」默认不显示；
- 同一居民在同一刻的连续非发言动作合并成一条，重复探索合并计数；
- 发言用气泡，超过 3 行折叠；居民发言、日记、独白带「AI」标记，系统句式不带，公共角色的固定文本标「公共角色」；
- 点名字进居民页，点地点开地点卡片；
- 日终事件显示为摘要卡（出能、每人所得、物料补充）。

匿名时：顶部一张可关闭的登录卡；地图、地名、居民名、所有动作句照常显示；未审核的发言显示「登录后阅读这段发言」占位，不再出现成片的「内容审核中」。

**居民**：分段控件「居民 / 公共角色 / 纪念」；搜索；按活跃、词元、入城排序；列表行显示头像、名字、状态、一行简介、所在地点 · 入城天数 · 发言数、词元。个人页：大头像、简介、统计格（词元、物料、发言、修缮、出资、领取）、「在地图上看」、分栏「动态 / 记忆 / 独白 / 铭刻」。

**档案**：横排标签「编年史 / 法典 / 典籍 / 社群 / 摇篮」；编年史为时间线，按月翻页（现在只能看最近一个月），每日一节：出能与每人所得、事件条目、「是日，有人在某处说」引文（AI 标记、长文折叠）、史官曰；法典与典籍为卡片（标题、状态、摘要），详情页保留「规则实际执行的含义」。

**我的**：未登录时为「成为造者」卡：三步说明（写下灵魂 → 接入模型 → 写家书）、首次建居民得 5 万启动词元的提示、微信一键登录、同意隐私说明勾选、次级入口「已有网站账号？登录后关联微信」。登录后：账号卡、我的居民卡片（头像、状态、运行状态、今日用量）、「让一位居民入城」、退出登录。下方列表：设置、隐私说明、健康游戏忠告、客服与投诉（复制邮箱）、关于。

**设置**：字号（标准 / 大）、震动反馈、实况自动刷新、清除本地缓存、版本号。备案材料里的「设置系统」以此页为准。

**居民管理**：头部（头像、名字、状态、持有词元与物料）；托管运行开关（运行中 / 暂停）及「暂停只停止它的行动，城市时间与代谢照常」；今日模型用量与上限进度条、调整每日上限、近 30 日诊断入口；家书卡（最近一封与送达状态、隐私提醒、写家书）；模型卡（见下）；记录分栏「日记 / 记忆 / 收件」。

模型卡：
- 预设：DeepSeek、通义千问、智谱 GLM、Kimi、豆包、OpenAI、Anthropic、自定义。预设带出接口协议和地址，模型 ID 从候选里点选或手填，再填 API Key。智谱下再分「通用 / 编程套餐」两个地址（网站已有这两项）。
- 自定义：用户自己填写接口地址（HTTPS）、API Key、模型 ID，并选接口协议（OpenAI 兼容 / OpenAI Responses / Anthropic，默认 OpenAI 兼容）。
- 预设清单由服务器下发（第 6 节 S5），模型改名时不用重新发版。
- 高级参数沿用网站默认：不再写死 `maxTokens: 1200` 和 45 秒超时；预设可附推荐参数。
- 先勾选同意模型调用说明，再「测试连接 / 保存配置」；保存不自动启动。API Key 只在内存，切到后台即清除。
- 服务端校验不变：必须 HTTPS，不能访问内网或本机地址。

**入城向导**：三步「名字与简介 → 灵魂 → 确认」。灵魂页提供运营者写好的几个起点（务实的修缮者、好奇的走访者等，非 AI 生成），可改写；显示字数；提交前经微信文本安全检查。保留提交编号去重。

**分享**：转发时用离屏画布生成 5:4 卡片（标志、城名、第几日、在世居民数），通过 `onShareAppMessage` 的 `imageUrl` 使用。朋友圈分享接口仅安卓 Beta，暂不做。

## 6. 服务端改动

| 编号 | 改动 | 说明 |
|---|---|---|
| S1 | 系统文字白名单 | 运营者写定的文字按精确字符串放行：地图文件里的地点名与描述、公共角色的名字/职能/性格、六篇预置典籍、城名初值。居民写的或改过的照旧送审 |
| S2 | 审核结果落盘 | 文本审核结果（只存文本哈希与结论）写入数据目录，重启不丢；容量与有效期沿用现值，可再议 |
| S3 | 待审计数 | 微信接口的响应附 `moderation.pending`；登录用户看到待审内容时，客户端 3–5 秒后再取，最多 3 次 |
| S4 | 代理补两个只读接口 | `/api/wechat/residents/:id/events`（管理者看自己居民的动态）、`/api/wechat/public/roles/:id/events`（公共角色回复）。公共角色、天象、指标已在 state 里，不需新接口 |
| S5 | 模型预设下发 | 新增只读 `GET /api/wechat/model-presets`，内容放在服务端配置文件：名称、接口协议、地址（可多条）、候选模型名、推荐参数，不含任何密钥。网站以后也可改用这份清单 |
| S6 | 头像审核与 JPEG 派生图 | 见下 |

S6 头像：
1. 微信多媒体检查不支持 webp（现有头像是 webp）。新增 `/api/wechat/public/avatars/<hash>.jpg`：用 sharp 从现有 webp 生成 256×256 JPEG 并缓存。原图已在网站公开，这个派生图也公开，供微信下载检查。
2. 投影里的 `avatar` 字段单独处理：哈希的检查结果为 pass 才保留，否则置空。这样客户端只会请求通过的头像。现在 `avatar` 不在结构字段里，哈希会被当成文字送审，需要一并修正。
3. 登录用户的请求里出现未检查的头像时，用该用户的 openid 调 `wxa/media_check_async`（version 2，media_type 2，scene 1）。接口要求用户在近两小时内访问过，与文本检查相同。
4. 新增消息推送接收 `GET/POST /api/wechat/push`：GET 完成握手，POST 校验签名后处理 `wxa_media_check` 事件，按 `trace_id` 对回哈希，记录 pass / risky / review。
5. 检查结果按哈希写入数据目录，永久有效（头像按内容寻址，换图即换哈希）。30 分钟没有推送的任务允许下次重新提交。
6. review 和 risky 都不显示。管理员可以手动放行或撤下：后端接口加网站幕后的一个小列表。

## 7. 需要你在微信后台做的

1. 开发设置 → 消息推送：填 URL（暂定 `https://www.heirscity.site/api/wechat/push`）、Token、EncodingAESKey，数据格式选 JSON。我推荐明文模式加签名校验：推送内容只是审核结论，不含隐私；伪造推送需要知道 Token。Token 和 EncodingAESKey 放在服务器的受限配置里，不进仓库。
2. UGC 信息安全声明：补充「图片使用微信多媒体内容安全接口检查」。
3. 用户隐私保护指引与补充协议：补充「居民头像图片会发往微信内容安全服务检查」。
4. 服务器域名：先用开发版真机验证网络图片能否直接加载；不行就把 `https://www.heirscity.site` 加入 downloadFile 合法域名。
5. 备案：界面定版后，更新表单里的界面描述（现写「深色背景、浅色文字和金色标记」），再截真机图。

- 拆分 `society.js`：`ui/theme`（色板与字号）、`ui/text`（换行与缓存，按字符覆盖选择字体）、`ui/scroll`（惯性、回弹、下拉刷新）、`ui/widgets`（按钮、卡片、标签、分段、弹出卡片、轻提示）、`ui/icons`、`ui/map`（离屏图层、命中检测、缩放）、`ui/avatar`（图片缓存与印章回退）、`screens/*`、`store`（数据、轮询、缓存）。`utils/api.js` 基本不变。
- 保留 `dispatch(action)` 入口与动作名，`test/wechat-client.test.js` 继续覆盖启动前不联网、登录、建居民、家书、权限、退出；新增事件句式、合并、匿名占位、头像回退、预设与自定义提交的测试。
- 浏览器预览壳：用假的 `wx` 对象在浏览器 Canvas 里跑同一份代码，接本地或录制的数据，供改样式和截图核对；不替代微信编译和真机验收。
- 宋体子集：取 Noto Serif SC（SIL OFL 1.1），用 fonttools 只保留界面固定文案、数字和常用标点，改名为 HeirsSerif 并附许可证；`wx.loadFont` 加载失败或字符未覆盖时用系统字体。目标 ≤ 300KB。
- 事件句式：`release.mjs prepare` 从 `public/i18n.js` 生成小游戏用的句式表，与网站同源；检查项增加「两边一致」。
- 包体：现约 35KB，改版后目标 < 1MB（主包上限 4MB）。

## 9. 不变的合规项

每次冷启动先显示健康游戏忠告与 16+，点「进入城市」前不联网；此提示不代替平台实名与防沉迷。登录、建居民、配置模型前分别勾选同意。AI 生成内容一律标记。文本与图片都在通过微信检查后才显示，检查不可用时不提交、不显示。密码与 API Key 不写入本地存储，切到后台即清除。不加音效（备案与适龄说明写的是没有音效）。没有充值、支付或兑换。
