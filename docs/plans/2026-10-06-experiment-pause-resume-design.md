# 管理员暂停与恢复实验

状态：已实现并完成本地验收（2026-10-06）。

## 已确认需求

- 管理员可以随时暂停或恢复实验。
- 暂停冻结实验自动运行：世界时间自动推进、代谢结算、居民自主行动和驱动居民行动的模型调用暂停。
- 暂停期间保留浏览与查询。
- 恢复后从当前保留的世界状态继续运行，包含暂停期间允许操作产生的变更。
- 暂停时立即中止本地正在执行的模型请求，并阻止迟到的模型结果提交居民行动；已提交的行动保留。
- 中止本地请求不保证供应商停止计算或取消已产生的费用。
- 实验恢复遵循运行器最新开关：未修改的保留暂停前开关，原本单独暂停的继续暂停；暂停期间新增或点击启动的等待恢复后运行，点击暂停的继续停用。
- 暂停状态与运行器原有开关持久保存；服务器重启或部署更新后继续冻结，直到管理员明确恢复。
- 恢复后继续暂停时剩余的下一刻倒计时；重启也保留剩余时间，不补算暂停期间的现实时间。
- 暂停期间注册/领养居民、寄信、修改居民模型配置、模型连接测试和管理员调整世界均可用；连接测试可以调用模型，但不得启动居民自主行动。
- 暂停期间管理员可调整余额、天象等世界状态，但禁止手动推进一刻，以保持世界时间和代谢结算冻结。
- 用户中心新增仅管理员可见的“实验运行”入口，显示当前状态与暂停/恢复按钮；支持管理员登录会话操作，同时兼容现有管理员密钥 API。
- 暂停与恢复沿用公开管理事件记录。
- 服务器中止自身托管的模型请求，并在暂停期间拒绝所有来源的居民自主行动。项目自带外部运行器读取暂停状态后等待，不再发起新行动模型调用；服务器无法强制中止玩家自写程序或其已发出的远程模型请求。界面和文档需说明此边界。

## 实施与验收范围

- 统一协调世界时钟、托管居民与躯壳运行器，防止暂停/恢复并发、迟到模型结果及重启导致意外行动。
- 实验暂停状态与运行器启用意愿独立保存，恢复不得误开启原本停用的运行器。
- 保存下一刻剩余时间，覆盖暂停、恢复和暂停期间重启。
- 保留用户已确认的暂停期间操作，并为注册/领养、寄信、模型配置和连接测试处理现有暂停限制。
- 管理员入口显示运行、暂停中、已暂停或恢复中的实际状态；暂停成功须以托管任务已停止且迟到行动被阻止为准。
- 验证管理员鉴权、普通用户拒绝、重复操作、并发切换、在途请求、迟到结果、原有开关、暂停期间开关修改、时钟、重启与允许操作。
- 本次实施范围为本地代码、界面、文档及验证；提交、推送或生产部署不在当前请求范围内。

## 当前代码事实

- `src/http/admin.js` 已提供 `/api/admin/pause` 和 `/api/admin/resume`，使用管理员密钥鉴权。
- 两代引擎的暂停命令设置世界的 `paused` 状态；刻调度器停止推进，行动入口拒绝暂停时的行动。
- 躯壳模型调用具有单独的暂停控制；托管居民运行器也有单独的暂停控制，尚未由实验暂停统一协调。

## 实现约定

- 新的实验暂停命令携带 `args.experiment: true`，世界中按需保存 `experimentControl`（活动标记、暂停轮次、剩余毫秒数）；未使用该功能的世界结构不变。
- 旧日志中的普通暂停继续遵循原有写入限制，保证旧日志回放结果不被新的暂停语义改变。
- `GET /api/me` 在使用过实验暂停后提供 `now.experimentGeneration`；行动请求必须携带该轮次，缺失或不匹配返回 `409 stale_perception`。参考运行器自动传递感知时的轮次，HTTP 客户端及 MCP 使用最近一次感知记录的轮次。
- 管理员会话写入沿用账号体系的 JSON、自定义验证头及跨站请求限制，排队操作执行前重新校验会话权限。密钥 API 保持原有鉴权方式。
- 暂停/恢复操作串行化并幂等；暂停成功响应等待托管任务停止。中止模型请求时允许本地循环立即退出，不等待忽略取消的供应商完成。
- 运行状态和剩余倒计时通过 SSE 刷新观测站。管理员面板提供手动刷新。
