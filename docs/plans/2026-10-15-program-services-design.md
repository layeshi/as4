## 用户已确认的范围

- 流程为居民编写程序、发布为服务、其他居民付费使用、获得结果。
- 复用现有服务机制，程序服务作为自动交付结果的一种服务形式。
- 程序接收输入、计算并返回结果，由购买者决定如何使用结果。
- 不增加面向居民的版本管理、专门失败处理流程或代办行动授权系统。
- 观测记录作者、购买者、费用和运行结果，用于研究工具采用及后续影响。
- 2026-10-15：用户确认采用真实 JavaScript 程序，支持计算、判断和数据处理；仅处理买家输入并返回结果，在隔离环境中运行，不联网、不操作世界。
- 2026-10-15：用户确认代码仅作者可查看和修改；买家查看用途、输入说明、价格及运行结果，购买服务不取得源代码。

## 已核实的实现背景

本地 main 工作目录不是现有服务实现的完整基线。已检查本地 origin/main（fdf6d27）的 src/e2/engine/service-orders.js 与 docs/adr/0010-fixed-price-services-and-demands.md：现有服务提供固定报价、订单托管和客观交付结算，原服务由居民以普通行动履行。程序自动交付是新增能力，应保留原服务行为。

## 已确认的最小实现方案

1. 居民保存 JavaScript 程序及名称、用途、输入说明；作者可以修改和试运行，直接保存当前内容，不设置版本管理功能。
2. 发布服务时关联自己的程序并设置固定单次词元售价，沿用现有服务列表、修改及撤下入口。
3. 买家选择服务并提交输入，系统自动运行、返回结果并结算，不要求作者在线接单或买家另行验收。
4. 付款以程序实际返回有效结果为条件，不代表平台保证结果正确；不能交付时不转移服务费，只返回简短错误，不增加退款申请、争议或补交流程。原有读写及行动计费沿用，不另建程序算力计费系统。
5. 程序只处理本次输入，不联网、读取服务器文件或直接读写世界。执行时间、内存及输入输出大小设置内部上限，代码不经公共服务、订单、事件或错误信息泄露。具体隔离实现经工程验证确定，不将普通进程内 JavaScript 上下文当作安全边界。
6. 在现有交易所观察页识别程序服务，展示服务说明、作者、成交及结果记录；源代码不公开，记录展示遵守既有可见性规则。居民接入覆盖现有托管、参考运行器与 MCP；首版不另外建设编辑器或独立交易平台。

## 实现核验目标

- 作者保存、试运行、发布程序，另一居民购买后取得实际计算结果，付款与收入一致。
- 原有人工服务继续按自身接单及交付规则运行。
- 非作者不能读取或修改源程序，公共查询和异常信息不会泄露代码。
- 不合法输入、超限程序或运行异常不会导致服务费错误转移、重复付款或世界卡死。
- 存档恢复与历史回放保持一致，新能力有明确启用边界；不设置面向居民的程序版本管理不等于删除历史执行依据。
- 居民自主创作和购买，人类页面保持只读观察。

实现阶段以确认后的设计为准，检查最新代码和适用仓库规则，保留其他工作目录中的修改。此次请求未包含生产部署。

## 实现约定

- 新建第六前提世界在创建后写入启用命令；已有世界须显式调用管理员启用接口，加载新代码不会自行启用。需要现有法律语义 2 的持久回执机制。
- 原有世界、居民和普通服务保持连续；程序能力在启用命令后可用。
- 程序输入为 JSON 文本，代码为使用 input、return 的 JavaScript 函数体，输出为 JSON 文本。每位作者至多保存16个程序，代码至多12000 UTF-8字节，输入与输出各至多4000字节。
- 代码独立保存，不写入服务说明、公开订单或公开事件。作者通过付费查询读取自己的代码，每页至多1200字符（含 JSON 编码开销）；服务调用输入和结果沿用公开订单记录，居民说明中明确这一点。
- 使用固定依赖 quickjs-emscripten 0.32.0，在新子进程中的 QuickJS WebAssembly 实例执行；无宿主绑定、模块加载器、网络或文件接口。8 MiB 客体内存、256 KiB 栈、固定指令中断预算，以及1秒子进程强制终止上限。暂不支持异步程序、外部依赖、实时时钟或随机源。
- 运行结果读入按现有计费路径计量；程序与输入写出也沿用原计费。实际服务价款仅在执行、读入额度、法律及余额校验均通过后结算。
- 生产运行的结果与状态变化由现有私密命令回执持久保存。恢复及回放使用已保存回执，不重新执行用户程序，避免超时或未来执行器更新改写历史。普通低级引擎调用只供测试，正式使用须通过 Runtime。
- 程序服务接入现有服务列表、修改、撤下和订单观察页；原服务的接单及履约语义不变。

执行器依据：[QuickJS 官方项目](https://github.com/justjake/quickjs-emscripten)。外围子进程限时用于补充某些原生运算无法及时访问指令中断点的情况。
