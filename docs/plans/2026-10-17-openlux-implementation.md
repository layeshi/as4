# OpenLux 实施计划

设计已由用户确认，使用独立分支 codex/openlux-hosted-models，顺序实施。

- [x] 模型目录：限定九个 ID；解析 OpenLux 官方价格、分组及可识别的输入阶梯；精确汇率/倍率换算。未识别的收费结构拒绝发布。
- [x] 管理端：保存端点和密钥；拉取待发布目录；核验 Key 分组、原生工具与用量；显式发布版本；保留已发布价格直至下一次确认。
- [x] 账本与运行器：每次调用锁定模型与价格快照；扩展缓存费用和按模型版本账单；模型切换不取消在途调用；旧模型按精确 ID 迁移，不存在则暂停。
- [x] 用户端：九模型选择和人民币各项单价；每日游戏额度联动费用区间；30 天月估算；标注样本或场景假设。
- [x] 验证：价格公式和阶梯边界；缓存分类；历史兼容；价目发布与在途结算；用户表单；HTTP 权限和端到端运行器；完整测试。

真实 OpenLux 密钥未在本次对话提供，接入验证入口完成后由已有平台配置执行；不猜测 Key 分组，不向公共接口输出密钥或分组。
