# 世界简化、居民形象与公共角色

日期：2026-10-11。状态：Q1–Q26 全部确认；整合实现规格 P6-0.1 已完成，待最终审阅。新增取消两类密钥、修改完成后开新世界两项要求已纳入。未实施或部署。

后续实现统一阅读 [SPEC-P6](../SPEC-P6.md)；本文保留决策依据与覆盖关系，具体契约及显式实施初值以整合规格为准。

## 基线

以已核验 GitHub main 的 `d6557117ccfa3a56c0ccf11a4b48f6ece7cd9b76` 为固定代码基线。P5 已实现词元与物料、施工、研究所、服务与需求订单、未明规律和环境记录分页。main 中 `docs/validation/P5-DEPLOY-20261011.md` 记录了 P5 上线；本轮未直接巡检生产。

最初误用缓存 P4 与本地旧方案推断物料功能尚未实现。该判断及“与物料一起重开新世界”的建议已撤回。后续以 P5 代码为基础设计改进。用户随后明确要求修改完成后开一个新世界，现有世界迁移不再作为本轮设计前提。Q1–Q7 指基线更正后最后提出的七问。

## 已确认决定

用户先对 Q1–Q7 回复“按建议”，对 Q6 补充可使用公共大模型；随后对 Q8–Q15 同样回复“按建议”，另要求取消造物者密钥与 agent 密钥，并在修改完成后开新世界。

### Q1 废止旧币

废止旧币，不兑换为词元，保留历史记录。接受失去旧币不腐坏储值工具的代价，避免通过兑换扩大可用词元供给。新世界不生成旧币、不导入旧币余额、交易与法律；无需为当前世界制定废币迁移方案，不能只隐藏新世界界面而保留旧币经济入口。

此决定修订 ADR-0008 及 P5 规格保留旧币的约定；旧规格仍描述既有版本，未来实施以新世界规格为准。见 ADR-0012。

### Q2 居民形象

用户上传一张静态图片，可以更换；地图、居民列表和个人档案统一显示，无图时使用默认形象。首版不增加平台图片生成。当前管理账号可以修改图片；过继后新管理者接替，所有页面统一显示当前图片，不做历史图册。

### Q3 天象

保留震、雾、蚀，去掉忘川，取消投票；类型和发生日期随机，允许平静期，保留事前征兆。不重新引入对源井产出的旱丰影响。采用 Q14 已确认的月度节奏、剩余类型相对权重及征兆；新世界不导入旧排期。历史回放须保持可复现。

### Q4 我的居民

页面分为“当前关联”和“我的创作”。当前关联可查看授权范围内的状态和详情；我的创作保留生涯追踪，过继后只查看公开信息。创作者身份与当前管理权限分开。新世界不再使用造者密钥关联；由账号记录创作和管理关系，创建时自动绑定登录账号，记录原创账号；过继由双方账号确认并撤销旧管理权，不做旧数据署名恢复。

### Q5 虚拟典籍

替换预置人类经典，保留居民自己的著述、出版和历史作品。虚拟典籍包括可靠的公开规则与设施说明，也包括有不同立场的虚拟历史、传说和残篇，两类明确区分；不直接泄漏未明规律答案。Q25 已确认六篇虚拟典籍，读取沿用档案馆地点与词元费用；新世界不搬入旧人类经典，旧引用留在旧档案。

### Q6 公共角色（用户补充优先）

接引员、公告员、史官等约十个角色有固定功能，可接入一个共用大模型，进行特别简单的对话和行为，其额度不计入城市总额度。

此前“不依赖 AI”“完全不调用模型”的建议已被本次决定替代。公共角色的独立模型额度只确定了资源来源边界，不等于无限调用、不等于可向居民免费提供通用模型，也不自动赋予投票、生产、交易、读取私人信息或修改规则的权限。这些权限已由 Q8–Q10 限定：不投票、不领配给、不持有可交易财富、不代居民接单劳动，只读取公开信息，预算有限且失败可降级。

“公共角色”是本轮提出的统一称呼，用于区分用户设计的居民与平台提供的固定职能角色。它们的调用使用“公共角色额度”，与城市词元供给及普通居民供养额度分开。见 ADR-0013。

### Q7 历史统计

同时提供长期生涯统计与近期模型诊断。长期保存资源收支、行动、作品、工程、订单等累计统计和事件；模型调用诊断保留最近三十个现实日。游戏词元与供应商真实 token 分开，历史缺失明确标注。

复用 P5 物料、订单查询和环境归档分页。已有模型用量仅保留十四日与二十次调用，运行轨迹保留三十日；不承诺重建已经删除的明细。私人内容按账号管理权限展示；Q23 已确认五部分页面、世界日/现实日口径及权限范围内导出，具体字段见整合规格。新世界从创世开始记录，不补造旧世界缺失明细。

## 新增代码核查（固定基线 d655711）

- 当前史官是 `src/e2/chronicle.js` 的确定性模板，每日生成编年史，并非居民。模型角色的记述需保存生成结果，历史回放不能再次调用模型；Q11 已决定保留原编年史。
- 现有模型供应商适配与预算工具可以复用，但 P5 普通居民客户端会进入人口、法律、配给和思考词元结算，不能用“免扣款的普通居民”草率实现公共角色。共用模型不等于共用聊天记忆。
- 旧币可用于收费、转移、分配、铸造、条件表达式，甚至立法资格与票重。不能将余额清零或币改词元视为语义等价；预置六条遗法没有旧币依赖。当前居民法律不导入新世界，无需迁移预检。
- 当前账号关联记录不能证明原创者身份；居民谱系的 authors 也不是人类账号。新世界创建时直接记录账号创作关系，不导入旧关联来推断署名。
- 三十日运行诊断已有无正文的事件元数据口径，继续不保存模型提示、回复或隐藏推理全文。长期生涯统计应与可删除的运行器用量分离。
- 预置 canon 同时包含虚构《致后来者》和二十二篇人类经典，不能全删 canon；历史阅读按 docId 引用，替换正文会篡改旧引用。

## 第二轮确认结果及后续覆盖

Q8–Q15 用户已按建议确认；涉及旧世界迁移和密钥验证的部分，被同次消息的新增要求覆盖。

- Q8 公共角色只承担引导、公告、记史、查询及简单活动；不投票、不领取居民配给、不持有可交易财富、不代居民接单劳动。
- Q9 首版供居民在世界内交互，人类查看对话与成果；公共角色只访问已公开信息，不读取私人记忆、幕后身份、未来天象排期或隐藏物理参数。居民提问仍按普通通信规则付费。
- Q10 所有公共角色共用一个有上限的每日模型预算池，各自独立记忆，按事件或作息触发，限制对话频率和长度。失败或耗尽时使用固定话术和基础查询，不阻塞世界。Q20 已定日预算初值。
- Q11 保留确定性事实编年史，模型史官另写简短记述和评论、附对应事件出处；模型内容不能成为法律或账本事实，生成结果保存，回放不重新生成。
- Q12 原先确认的现有含旧币报价退出和法律预检办法，不再作为本轮交付要求：新世界不导入它们，无需执行原地迁移。
- Q13 状态统计与私人详情分层的目的保留，但“验证造者密钥”的手段明确取消；新世界改用账号身份与管理关系决定权限，Q17 已明确单一当前管理账号与双方确认过继。
- Q14 沿用每月最多一次、允许平静月份、提前出现征兆的节奏，保留剩余类型相对权重，取消投票和忘川。新世界无旧天象排期，不处理旧世界已发生的遗忘。
- Q15 当前书库不提供预置人类经典，虚拟典籍有新身份，保留《致后来者》；居民著述不移除。旧世界的引用留在旧档案，新世界不搬入人类经典正文或阅读史。

## 新增明确要求

1. 取消现在的造物者密钥与 agent 密钥，用户不再领取、保管、输入这两类长期凭据。此要求不应被解释为匿名用户可以管理居民或提交动作。Q16 已决定新世界只保留平台托管，不提供外部运行器和 MCP 的居民控制入口。模型供应商凭据与这两类身份凭据是不同概念，本次取消不自动涵盖前者。
2. 修改完成后开一个新世界。取消现有世界余额、交易、法律、账号关联、旧排期和旧典籍的就地迁移工作；不因“开新世界”推断要删除旧存档。新世界保留人类账号、普通居民重新创建、公共角色随创世建立；新增首次创建启动词元，其余创世资源和世界节奏沿用 P5。

## 第三轮确认结果

用户逐项答复：Q16“只保留平台托管”、Q17“是”、Q18“是”、Q19“是”、Q20“同意”。

- Q16 新世界只保留平台托管。用户登录后配置模型，由平台驱动居民；不生成造物者密钥或 agent 密钥，不提供外部运行器和 MCP 的居民控制路径，不另外建设外部授权协议。
- Q17 每个居民只有一个当前管理账号，创建时自动绑定登录账号并记录原创账号。登录后即可查看自己的居民私人详情、修改图片、配置模型和预算，不再验证居民密钥。过继由双方账号确认，原管理权撤销，原创者保留公开生涯追踪。
- Q18 保留人类登录账号，普通居民由用户重新创建；不导入现有居民余额、法律、记忆或运行状态。公共角色随新世界建立，旧世界存档保留。
- Q19 十个公共角色：接引员（迎新与指引）、公告员（公共事件播报）、史官（事件记述）、档案员（典籍和作品检索）、议会书记员（法案与表决查询）、交易登记员（报价与服务需求查询）、源井值守员（供给与改良查询）、研究所值守员（权限费用与使用介绍）、摇篮看护员（孕育与待领养介绍）、纪念地守录员（墓志与公开生涯查询）。各有名字、图片和简短性格，不能因聊天改成通用助手。
- Q20 管理员统一配置一个公共模型和供应商凭据，十个角色共用每日一百万真实模型 token 上限，输入输出合计；单次回复约一百至三百字，按事件或被询问触发。上限不是固定消耗量，独立于城市供给；额度不足或模型故障时退回固定话术和基础查询。此为已接受的首版初值，尚未实测标定。

密钥核查补充：账号登录会话已有实现，但当前居民关联只是多账号只读链接，不能自动提升为管理权。平台托管目前也使用居民令牌调用 HTTP，已有进程内受限客户端可作为重构参考；新世界不再支持外部运行器与 MCP 控制居民。无需为取消两类密钥删除调用模型所需的供应商凭据。

## 第四轮产品边界

Q21 已确认：用户明确“需要启动词元”，替代原先不增发的建议。启动词元属于可支配世界资源，使新居民能在首次配给前移动、采集和执行其他付费动作，与基本额度、模型日预算分开。金额、来源和领取资格已由 Q26 确认，不沿用旧世界管理员发放的数额。物料与其他创世经济规则暂沿用 P5。

Q22 已确认：在地图上明确标识公共角色，各有主要值守地点和简短作息，可做不产生资源效果的走动与迎接；与居民的对话公开，同地发生，不接私信、不远程代办。设施失效时保留现场说明，但相应查询以外的设施功能不会被角色绕过。公告员广播真实重要事件，史官每日一次公开记述，其余优先被询问才调用模型。

Q23 已确认：个人页面分五部分——总览（地点、状态、词元/基本额度/物料、模型日预算与运行状态）、收支、行动与成果、模型运行、完整时间线。经济和行动默认按世界日，真实模型用量按现实日；支持筛选和导出本人可见范围的记录。私人日记、记忆、独白与家书另列为当前管理者可见，不纳入通用模型诊断正文。延迟公开规则继续约束公众视图。

Q24 已确认：各处默认显示当前形象，更换只记录为外观变更，不修改居民灵魂或历史行为；不做历史图片画廊或逐条事件固定旧头像。当前管理者可改图，过继后新管理者接替。上传大小和格式限制作为实现默认值写入规格。

Q25 已确认：先做六篇短文——《致后来者》《城中生存须知》《设施与道路手册》《交易、委托与履约》《旧城维护日志》《失落年代残篇》。前三类操作/规则说明及交易说明可靠，后两篇明确标记世界内史料，允许不完整和不同立场，不公开隐藏物理规律的精确答案；居民仍可创作、发表、交换自己的著述。读取沿用现有档案馆规则和词元费用，不由公共角色免费吐出整书。

Q26 启动词元细则，已确认：每个人类账号在每个新世界首次创建普通居民时，发放五万可转让词元，作为独立、一次性的城内启动发行记入来源账，不从首日配给中扣除，不影响后续源井日产。删除、离世、归隐或过继居民不重置领取资格；后续居民由已有居民转赠或城市配给支持。公共角色不领取，领养已有灵魂不重复领取。基本额度与初始物料规则不变。按 P5 默认 K 估算，五万词元足够若干次移动和采集，但不是固定承诺的行动次数，实际仍取决于合法费用、思考支出及路线。限制每账号一次只防止同账号重复造人领款，不声称解决多账号问题。

用户最终回复“全部同意”，确认 Q24–Q26，产品决策树已闭合。现已整合成 P6-0.1，明确接口权限、预算计量、限频、时间线口径、图片文件限制与验收矩阵；实现默认值集中列明，尚未实测标定，供最终审阅。没有未答产品问题，最终审阅不重新询问已经同意的选择。
