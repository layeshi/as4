# 地图升级实施计划（P2 + P3）

**目标：** 地图从写死的 12 处地点改为数据驱动；新世界使用更大的「边疆」地图：城区扩到 18 处，城外荒野拆成 5 个地带（共 23 处），移动按路程计价；观测站改为赛博朋克 + 废土风格、可缩放平移的地图。

**已定的决定（2026-09-30）：**

1. 做 P2（地图数据化）+ P3（扩城与边疆）。
2. 移动按路程计价：沿街道每段 1，正常运转的道路那段为 0，出发地的代价倍率照旧。
3. 只用于新世界或下一纪元：现有世界（baihua、mycity）保持经典地图，行为逐位不变，回放结果不变。
4. 观测站地图风格：赛博朋克 + 废土。

**架构：**

- `src/map/`：每张地图一个定义文件（地点的物理属性、坐标、街区、街道图、荒野地带的储量与遗物、地形），`classic`（附录 B 的 12 处）与 `frontier`（边疆）。引擎、感知、可见性、沙盘脑都通过 `src/map/index.js` 的查询函数取地点，不再使用全局的 `PLACE_IDS`。
- 世界状态：边疆世界记 `w.map = "frontier"` 与 `w.regions`（各荒野地带的储量与遗物顺序）；经典世界不写这两个字段（缺省即经典），所以旧快照、旧命令日志的回放哈希不变。
- 新世界用哪张地图由 `MAP` 环境变量决定，默认 `frontier`；只在创建世界时生效。回放按快照里的 `map` 重建。
- 公共接口新增 `GET /api/public/map`（静态地图数据，不含种子）；`state` 增加 `world.map` 与 `regions`。
- 观测站：地图渲染按地图数据绘制；SVG 分层（地形、街道、建筑、居民、特效）+ 固定的天穹 HUD；滚轮 / 拖拽 / 双指缩放平移，按缩放级别显示细节。继续零依赖、无构建、符合现有 CSP。

**技术：** Node.js 内置模块、原生 ES 模块与 SVG、现有中英词条与 CSS 变量。

## 边疆地图的内容

城区 18 处（原 11 处的物理不变，新 7 处都是 `none` 类型：有完好度、有墙、没有额外机制——看它们会被修缮、改名、重新诠释，还是任其坍塌）：

| 街区 | 地点 |
|---|---|
| 港区 | 港口、灯塔* |
| 旧城 | 学堂、图书馆、钟楼*、议会、法院 |
| 市井 | 广场、市场、剧场*、高架桥*、公寓* |
| 水脉 | 源井、医院、墓园、地铁站* |
| 东郊 | 神殿、工坊* |

城外荒野 5 个地带（`open` 类型，没有完好度，各有能量 / 旧币储量与每日再生，`explore` 在任一地带可用；被放逐者只能在各地带之间移动）：

| 地带 | 能量上限 / 日再生 | 旧币 | 遗物 |
|---|---|---|---|
| 荒野（近郊） | 400 / 20 | 100 | 7 |
| 废车场* | 250 / 10 | 250 | 7 |
| 光伏田* | 500 / 25 | 0 | 5 |
| 盐滩* | 150 / 5 | 50 | 5 |
| 公路尽头* | 200 / 10 | 100 | 4 |

合计能量上限 1500、日再生 70、旧币 500（经典荒野为 800 / 40 / 300）；遗物 28 件 = 原 16 件分散到各地带 + 新写 12 件（接续「半张地图」的线索，多语言译文待母语者校对）。

街道图：城内相邻地点之间 1；城门两处（市场—荒野、神殿—光伏田）与地铁隧道（地铁站—盐滩）连到城外。从港口到广场 2、到荒野 4、到公路尽头 7。

## 步骤

1. 地图模块：`classic` 与 `frontier` 定义、查询函数（地点表、荒野地带、最短路代价）、定义自检测试。
2. 世界与引擎：按地图创建世界；`move` 按路程计价；`explore`、每日再生、放逐、感知、可见性、指标、遗产表、史官按地带处理；经典世界逐位不变。
3. 文案：新地点与街区的中英文名称与描述、新遗物、遗产表条目、按路程移动的动作说明。
4. 配置、运行时、回放、沙盘命令行（`MAP` / `--map`）；沙盘脑在边疆地图上按代价选路、按地带探索（经典地图上的决策与随机数消耗不变）。
5. 运行器渲染与 MCP：地点列表按街区分组并标出代价。
6. 公共接口：`/api/public/map`、`state.world.map`、`state.regions`。
7. 观测站：赛博朋克 + 废土风格的地图渲染、缩放平移、环境页的荒野地带表、实况与居民页的地点顺序。
8. 测试：地图定义、边疆世界的创建与确定性、按路程移动、各地带探索与守恒、感知与公开数据；经典世界回放哈希不变（baihua、mycity 的数据副本）。
9. 文档：SPEC 新增附录 C 与相关章节、PROTOCOL、README、QUESTIONS；沙盘跑边疆地图并把结果写进 CALIBRATION。
10. 浏览器验证：独立临时世界上检查新地图的缩放、渲染与实时更新。
