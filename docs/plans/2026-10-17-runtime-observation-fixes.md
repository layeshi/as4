# 三城运行观测修复

线上审计发现两个统计缺陷：全岛公民指标仍检查单城裸标签；托管运行器在第六、七前提跳过注意力记录回调，导致接口把实际运行显示为零。

## 范围与口径

- 在全岛日结指标中，至少拥有一个有效城市的 `city:citizen` 标签的在世居民不计入非公民。位置、籍城不代替法律标签；多城身份只计一人。放逐指标独立统计至少拥有一个有效城市 `city:exiled` 标签的在世居民，同样去重。死亡、归隐者不计入。单城世界的既有口径不变。
- 恢复第六、七前提托管运行器的 `onWaking → TraceStore` 接线，包括模型调用前的资源拒绝。复用现有字段白名单、30天保留、管理员权限和公开聚合，不存提示或回复正文。模型名称使用实际生效配置。
- 城外普通建设空指针已由主线修复，沿用已有普通地点、道路和源井升级回归。

直接修日结生成与运行器接线，可让后续存档和所有接口共用同一结果。只在页面改数字会留下API错误；重写历史或用API调用次数推算唤醒次数会制造没有依据的数据，因此不采用。

## 验证与兼容

先用实际日结和真实HTTP服务上的mock托管运行复现失败，再修复。覆盖正常三城公民、跨城/多城标签、非公民、重复放逐、非在世居民，以及第六、七前提正常唤醒、资源拒绝、鉴权、公开脱敏和轨迹重新加载。跑现有城外建设、旧前提观测及完整回归。

不改变法律、身份标签、经济规则或模型设置，不自动补发资源。已落盘的旧日结统计不重写；旧回执仍按原状态哈希恢复，新日结采用正确统计。历史缺失轨迹无法从模型调用数可靠重建，本次不补造；注意力统计只反映实际留存的轨迹，部署当日也可能只有部分时段。此次提交不包含生产部署。

## 实际验证结果

- 基线专项：42项通过，0失败。
- 修复前新增回归：三城统计得到3而非0；P6/P7托管运行都未形成轨迹，分别稳定失败。
- 修复后专项：21项通过，0失败，包括正常唤醒、词元不足拒绝、公开脱敏、管理员鉴权、轨迹加载及已有城外建设回归。
- 完整 `node --test`：1885项，1884通过，0失败，1跳过，约170秒；包含旧前提、回放、随机规则和沙盘测试。
- `git diff --check` 通过。测试只用本地临时世界和mock模型，未访问生产模型接口。
