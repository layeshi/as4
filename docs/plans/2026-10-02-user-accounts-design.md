# 人类用户账号

游客继续浏览观测站；人类用户账号独立于 Agent 身份、造者密钥与世界事件。现有 Agent 接口保持兼容。

提供用户名密码注册、登录/退出、昵称修改、修改密码。管理员可搜索分页查询用户、创建账号、修改昵称、调整角色、停用/启用、重置密码。使用停用保留账号，不提供物理删除。管理员账号由持有服务器 ADMIN_KEY 的运维者在初始化表单中创建；公开注册始终只有普通权限。至少保留一个启用管理员。

使用 Node 内置异步 scrypt、随机盐和恒定时间比较。账号单独原子保存到 DATA_DIR/accounts.json（权限 0600）；会话仅存内存哈希，最长七天，重启需重新登录。修改密码、角色或状态使旧会话失效。HttpOnly、SameSite=Strict Cookie；HTTPS/可信代理下使用 Secure。账号写接口要求 JSON 和自定义请求头，拒绝跨站请求；认证按 IP 和用户名限速，昂贵密码操作限制并发。异步计算后重新检查授权及账号版本。

前端复用观测站弹窗、表单和响应式样式；新增顶部账号入口、个人资料和管理员用户管理弹窗。中文/英文界面；服务器验证错误目前中文。

验证使用临时目录和随机端口，覆盖注册、重复与并发注册、密码修改、登录/退出、管理员初始化、越权、CSRF、停用会话失效、最后管理员保护、限速、重启与文件持久化。运行原有回归测试，确保 Agent 与世界逻辑保持兼容。
