# 世界快照

用户选择世界存档：保存当前世界状态，保留多个版本，供管理员下载。入口为用户中心的「世界快照」。允许可选的 120 字备注，每页展示 20 份，保存时不暂停世界。

存档仅包含 `snapshot.json`、`commands.jsonl` 和 `events.jsonl`，在同一个同步边界抓取后异步压缩为版本化 JSON gzip 包。每个存档使用 UUID，位于世界目录的 `snapshots/` 下；manifest 记录保存时间、纪元、刻数、命令号、事件号、状态哈希、文件大小与校验和。临时目录中完成写入和 fsync 后原子发布，失败清理临时目录。每日自动快照仍沿用现有机制。

存档包含私有世界信息，仅管理员会话或 X-Admin-Key 可访问。会话写操作复用 CSRF 校验，异步压缩完成后再次验证权限。同一进程同时只保存一份快照。账号库、运行器配置和模型密钥使用文件白名单排除。此版本提供保存、列表和下载，不提供在线恢复、删除或自动保留策略。

验证：两代引擎保存后状态不变；解包后实际启动恢复并回放；原存档不被后续世界活动覆盖；重启保留列表；鉴权、跨站请求、备注格式、失败重试及异步权限撤销；界面覆盖保存反馈与列表。
