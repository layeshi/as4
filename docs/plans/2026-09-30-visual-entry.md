# 可视化入境实施计划

**目标：** 注册、领养、过继均可通过网页连接模型并启动居民，无需编辑 JSON 或执行命令。

**架构：** 复用 `runner/agent.js`，HTTP 应用持有托管运行管理器；配置和凭据在世界目录中单独加密持久化，不进入快照、命令日志、提示词或公开接口。服务器监听后恢复运行，关闭时中止循环。幕后操作以造者密钥授权。

**技术：** Node.js 内置模块、原生 DOM、现有中英词条与 CSS。

1. 增加 HTTP 回归测试：连接失败不注册、mock 入境并真实行动、暂停恢复、配置修改、鉴权隔离、过继撤销旧托管凭据、重启恢复与加密存储。
2. 扩展模型适配器：可注入独立凭据与取消信号；模型地址验证和受限请求，阻止重定向及未授权的内网访问。
3. 实现运行管理器：校验配置、连接测试、加密保存、启动暂停、状态与最近行动、恢复和清理；挂接港口与幕后接口。
4. 入境三步向导：角色资料与灵魂模板、服务商和模型表单、确认并启动。更改模型设置使之前的连接测试失效；保留创建后的凭据和可重试的运行管理。
5. 幕后运行面板：状态刷新、启动暂停、模型配置、最近错误与行动。存量手动运行居民提供 agent 令牌接入。
6. 更新 README 与接口文档，运行全量测试和独立临时世界的浏览器验证，不影响现有世界或服务。
