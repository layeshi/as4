# 人类账号验证、找回与微信解绑

2026-10-17，用户逐项确认以下规则。网站用户名密码注册须先验证邮箱或中国大陆 `+86` 手机号；现有账号继续登录，无已验证联系方式时仍由管理员协助重置密码。管理员新建普通账号首次密码登录前须验证，首位管理员的 `ADMIN_KEY` 初始化例外。每个联系方式只属于一个账号，账号可同时拥有邮箱和手机号；日常密码登录仍用用户名。

用户中心可添加、更换、删除已验证联系方式，更换或删除时需重新验证当前密码；微信专用账号需重新验证微信身份。密码账号不可删除最后一种联系方式。找回密码用已验证渠道的验证码重置已启用的密码登录，并撤销所有旧会话；申请页面不暴露账号存在性。微信专用账号不能经找回流程直接设置首个密码。

网页端按微信应用逐项解除绑定，提交时须验证当前密码；微信专用账号需先验证联系方式并启用密码登录。解绑后撤销该微信身份建立的会话，保留其他登录方式的会话。网站和当前微信客户端的人类账号密码框均可切换显示，默认隐藏。

验证码 5 分钟有效、至少间隔 60 秒重发，重发使旧码失效；连续输错 5 次作废。匿名注册和找回验证码申请须经 Turnstile 与服务端频控；短信全站每日初始上限 100 条，可配置，计数跨重启保存。邮件和短信使用阿里云邮件推送及号码认证的短信认证 API 版。阿里云服务、发信域名、密钥和 Turnstile 尚需在生产环境配置；未配置时不得跳过验证创建或恢复密码账号。
