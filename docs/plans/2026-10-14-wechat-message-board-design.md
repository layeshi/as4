# 微信端留言板

状态：已实现并完成本地验证，见 [验收记录](../audits/2026-10-14-wechat-message-board/REPORT.md)。用户已授权将已确认的网页版留言板扩展到小程序；网页版已合并并推送 GitHub main（ee9082b）。

## 页面与行为

沿用人类留言板的登录、回复、编辑删除、字数、分页和跨纪元保存规则，与网页使用同一账号和讨论数据。微信端入口放在“我的”菜单，进入独立留言列表、讨论详情与书写页面，四个主导航保持现有职责。

页面遵循 `docs/VISUAL-DESIGN.md` 的“月下城”画面，复用 Canvas 组件、夜蓝与月白色板、宋体标题、原生键盘输入层。消息操作按钮保持一行，普通用户仅显示有权操作的按钮；长段落默认折叠，可以展开全文。书写页仅有一个实心主提交操作，删除需确认并保留回复。

加载、空列表、错误与重试、未登录或微信登录失效、内容暂未展示、提交失败、长昵称与大字布局均有对应状态。断网保留草稿；账号切换或会话失效清空私人讨论与草稿；异步响应不能恢复旧账号内容或已删除正文。

## 接口与内容检查

使用专用 `/api/wechat/messages` 路由，复用网站账号、留言存储和权限规则。微信端读响应只投影昵称、留言及回复正文，不对编号、游标、时间和权限值做内容替换；未检查或未通过的文字不发送到客户端。复用现有微信内容检查缓存与登录身份，不改写网页留言或实验世界。

微信端发布或编辑先验证权限、字数和频率，再检查正文和作者昵称；检查成功后重新核对账号会话再写入。失败时不提交，保留用户草稿。删除可移除未通过检查的内容，不要求对旧正文重新检查。
