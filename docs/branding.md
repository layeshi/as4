# 后人纪品牌图片

界面与浏览器标签页统一使用由用户提供图片简化而来的古城、月亮与水面倒影标志，界面保留“后人纪”名称。

标志采用深蓝（#19364d）与米白（#ffedce）两色，保留圆月、三座塔楼、一处桥拱和两条倒影，去除纹理、窗户与零碎建筑，以适应小尺寸显示。

界面使用矢量源文件 `public/logo.svg`；`public/logo.png` 为同图的 512px 导出。浏览器使用由矢量源文件生成的 `public/favicon.ico` 和 `public/favicon.png`，其中 ICO 包含 16、32、48、64、128 与 256px 六种尺寸。外部背景透明。

部署时同时发布矢量源文件与导出的浏览器图标，保留现有世界与配置。
