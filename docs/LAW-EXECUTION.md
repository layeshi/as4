# 法律执行预算保障 v2

只作用于显式启用的第二前提世界。原法律AST、文字、领取资格、逐人施行顺序、取整、随机数和同条规则先收集后施行的语义保留。未启用的世界及迁移前历史继续使用原2000步求值器。

## 检查与启用

管理员可通过认证后的 `GET /api/admin/law-execution` 查看只读预检：启用状态、容量、现存法律/程序/章程/地点规则/待表决提案的成本证明，以及保护原因。此请求不推进世界。

`POST /api/admin/law-execution` 体为 `{"version":2}`，或 `{"version":2,"capacity":{...}}`。它是进入命令日志的显式版本迁移，不是改居民法律。迁移预检包含新配置自身占用的存档空间；不支持的现存规则会阻止迁移，返回具体成本路径，原法和旧配置保留。不能通过普通环境变量静默启用或改变容量，不能降级为旧版本。重复启用会保留已有容量；部分更新只覆盖明确提供的字段，null/false等错误类型被拒绝。

本次交付未在生产调用此接口。上线前应先一致性备份、验证目标代码对旧命令完整回放，再执行经授权的迁移。

## 执行与准入

每次规则收集使用固定的读取状态与惰性纯表达式缓存；不缓存sample或依赖随机数的父表达式。缓存区分it绑定，首次真正求值才缓存成功结果，不提前执行if/default未选中的分支。每次执行固定所用表达式树，全局解析缓存清空不影响计算步数和回放。

成本证明包含版本、规则哈希、每条规则计算步数上界、意图上界、字段路径及首次/重复计算成本。预算使用证明所得上界；普通数字/列表字段不能确定上界时报告cost_unproven，不将当时一次试算冒充保证。

正式propose、refound、社群/地点rules入口执行规则/程序成本与全城预留的统一检查；候选提案的旧程序快照和间接表决期间并存的旧规则也纳入。失败在扣动作能量前返回rule_invalid；draft仍可返回静态读法和budget诊断，预算不合格不执行预览，也不会被响应层误标为通过。

城市tick、出生/抵达、道路/建筑腐坏、项目、交易等事件多次触发的预留按保守倍数计算；实际执行还共享整条命令的步数/意图计量。每条受保护命令先在内存副本完成，只有全部通过才能提交；保持原世界及居民对象身份。超出证明或容量则放弃该命令的全部效果，保留安全截点并整体保护暂停。即使已普通实验暂停，新保护也立即落盘并通知驱动器停止。

保护暂停拒绝非恢复世界写入，保留读取与服务侧配置检查；普通实验暂停仍沿用原操作许可。`GET`中的required说明缺少何种容量。扩容迁移必须满足失败副本所需容量；旧容量不能清除保护。扩容并通过预检后，再通过正常管理员恢复接口恢复。不能跳过失败法律或部分转账。

## 默认支持容量与限制

默认512条居民记录、512摇篮记录、512社群/地点/道路/项目/孕育之约/身体/天气记录，1024交易记录和1024条规则。居民记录包含仍保留的死亡/归隐记录；这不是20具平台身体的人数上限。单条证明最多200000工作单位/8192意图，全命令最多2000000工作单位/32768意图，存档JSON最多64MiB，每刻动作上界4。代码对容量字段及组合给出上限，超出不能作为扩容输入。

实体上限与规则成本/事件倍数共同作用：并非任何512人法案或1024条规则都能同时获准。过于复杂或超过全城预留的候选法案仍被阻止。工作单位是确定性求值/遍历/排序计量，不是墙钟毫秒，也不构成生产延迟保证。每个新执行版本改变预算/优化语义时必须保留旧版本求值路径并使用新迁移版本。

0、1、14、32、128、512人的短历史合成世界日结在本机验证通过；512人约15.5ms、状态约0.6MiB，属于单次样本，不代表64MiB存档、最坏合法法案或生产服务器的SLA。未执行生产压测。

常驻指令是另一套居民动作语言，继续使用原有验证和限制；本次法律证明不覆盖其所有表达式。它触发的居民法律仍受命令级计量与原子保护。余额不足、法律政策不当、除零和溢出仍采用既有规则错误/兑付语义，计算保障不会代改政策或补发资源。
