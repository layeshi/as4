# OpenLux 平台托管模型

首批固定九个模型 ID，以设计文档中的名单为准。目录不会自动扩展；发布前逐个验证原生工具调用与用量返回。模型名称不作模糊替换，旧居民选择不在发布目录中时暂停并提示重新选模。

## 管理员接入

1. 打开管理后台的托管配置，填写 OpenLux 官方提供的推理接口地址与平台 Key，倍率初始 1.2、最大输出默认 4096。固定汇率为 1 美元 = 7 人民币。
2. 保存 OpenLux 设置。原 DeepSeek Key 不会被当作 OpenLux Key 自动复用。更换 Key 或接口会清空已核验目录；已有在途调用仍使用旧快照。
3. 点击“同步 OpenLux 价格”。只向 `https://www.openlux.ai/api/pricing_new` 读取公开价格，不发送平台 Key。生成的草稿尚不影响已发布价格。
4. 对每个需要开放的模型，核对平台 Key 在该模型上的实际分组。用户所说的“中间档”没有统一公共标识，不能用列表中位数、统一 `-2` 或网站默认最低价代替实际分组。
5. 点击逐模型验证。验证会向已配置模型接口发送一次工具调用测试，费用由平台承担。仅原生 `done` 工具调用与完整输入/输出用量都通过的模型可发布。
6. 勾选模型并确认发布。发布用所勾选项目替换当前目录，保留生成时间与唯一价格版本。未勾选模型不再接受新调用。后续上游调价或平台倍率变更仍需同步、核验和确认发布。

接入设置与草稿沿用现有加密文件 `hosted/model.enc`，Key 不返回用户接口、账单或日志。管理员负责核对 Key 分组；测试成功验证权限和协议，并不能独立证明 Key 的价格分组。

## 计费

- OpenLux token 模型的基础输入美元单价为 `2 × model_ratio × group_ratio`（每百万 token），输出和缓存项目继续乘对应倍率。
- 人民币单价为上游美元价 × 7 × 平台倍率。使用十进制有理数运算，最终单价向上取整到微元，单次费用再向上取整到微元，与原账本精度一致。
- 支持普通输入、缓存读取、5分钟写入、1小时写入。写入总量包含1小时写入；各项输入类别互斥，不重复计费。缺少价格不视作免费。
- 支持官方目录中按整次调用输入长度选档的阶梯；仅接收已识别的阶梯字段组合。输出长度或额外思考阶梯、按次计费、分组模型专属覆盖倍率等未适配规则拒绝发布。
- 每次调用前锁定模型、价格版本、美元来源、人民币价档、汇率与倍率；切换模型、发布价格或修改 Key 均不改写在途快照。
- 日账单按居民、模型、价格版本、实际价档与结算方式分别聚合，保留具体计费依据。原人民币余额及历史旧版记录不重新折算。
- 预留按各已知价档的保守最高单价计算。上游用量缺失或不可用时按全额预留结算，并标记为预留结算；失败或本地主动取消沿用原规则不扣费。
- 401/403/404 权限或模型错误，以及连续三次非取消调用失败，会暂停居民并提示换模型，不静默更换。

## 用户界面与预估

选模时展示各收费项目的最终人民币单价，阶梯模型展示各档价格。模型与每日游戏词元额度变化时重新计算预估；保存运行中托管模型会在下一次调用生效，不中断当前调用。

预估按每日额度用满计算，月费用为30天。游戏词元采用游戏读写权重，不等于服务商 token；预估不是人民币硬预算。

- 样本不足10个：明确标注粗估，展示实际 token/游戏词元为2–4倍、输出占10%–20%、缓存与价档的假设。这些数字是场景参数，不是九模型实测数据。
- 有足够完整醒来样本：使用该模型最近30天、最多100个样本，按当前各价档重算每游戏词元的费用场景，展示10%–90%分位。跨模型切换、失败或缺少用量的醒来不进入校准。
- 校准样本只保留计数，不保留提示词或模型回复。费用可能低于或高于展示区间。
