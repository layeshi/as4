## 发布前发现及修复

开发者工具实际连接线上 P7 后，发现城切换和城牌显示成「请微信登录后阅读」。匿名微信状态与地图接口可重复验证：三城固定名称、简称及地图引用被文字投影遮住，人类遗法也未进入三城的固定文本集合。

修复仅在 `w.premise === 7` 分支收集静态城定义，并同步挂载各城收集未被居民修改的人类遗法。居民自写的城名、法名和正文继续按原审核规则处理；不放宽通用字段规则，不改世界快照或历史，不影响前提 ≤6。

新增真实 HTTP 回归测试先复现失败，再验证三个城的名称、地图引用和遗法可读，同时验证居民改写仍被遮住。配套服务通过保状态发布更新，沿用当前 P7、七位居民、账号、模型与预算。
