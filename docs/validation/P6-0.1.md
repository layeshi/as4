## 新世界切换

只在完整测试通过后制作固定提交的独立release，安装锁文件依赖。停止 houren.service，确认正常退出，用受限目录备份整个数据、配置和服务文件；在备份副本进行旧世界完整回放和候选版本离线恢复校验。

在原数据根以服务用户执行：

```text
node src/tools/fresh-world.js OLD_WORLD_ID NEW_WORLD_ID OLD_RELEASE --offline
```

必须安全传入有效服务器环境；不把私有环境文件当Shell代码执行。新ID须唯一，旧snapshot与命令/事件日志须达到完整边界。工具不启动时钟或模型，不重置账号，不导入旧居民或经济。生成公开脱敏档案后将旧世界登记为只读。原始数据、旧程序release和备份保留。

P6最后生效配置为 PHYSICS=2、PREMISE=6、紧凑物料地图、随机天象、零先民/躯壳/沙盘。时间、供給和私有物理沿用现场。公共模型复用既有平台线路，另存加密配置与独立预算，不复用旧居民凭据。

切current前进行release摘要与服务UID权限预检，启动后核实实际进程、HTTP/业务数据、静态资源、SSE、原账号保留、新世界零普通居民/十公共角色和旧档案只读。故障现场另外保留；若新世界已产生用户操作，不覆盖其进展来回滚。
