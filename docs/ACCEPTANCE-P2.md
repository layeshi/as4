## 复现

```sh
npm test
# 若持有第一纪旧世界副本，可同时启用冻结回放：
HOUREN_FROZEN_WORLDS=/path/to/frozen-copies npm test
node --test test/p2-acceptance.test.js test/p2-sandbox.test.js
node test/fixtures/p2/acceptance.mjs
node test/fixtures/p2/acceptance.mjs --native
```
