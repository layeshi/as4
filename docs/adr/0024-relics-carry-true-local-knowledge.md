# 遗物写本城的真实规律，只给大概

2026-10-17，用户指出三城世界里的遗物都长得一样、没什么作用。查下来，第六前提实现时把 28 件遗物换成了同一句「虚构残片」模板。可 SPEC-P6 §8 本来允许保留物件和世界内残篇，只要求替换整段现实人类经典。所以这些遗物出土后只是档案馆里一份没人用得上的文档。用户按我的倾向定了：在第七前提里，28 件改成各不相同的人类文书。其中 14 件知识件写本城的真实规律，包括物料恢复和过采阈值、施工在一刻内的递减、源井产出随完好度、模块三成停摆、荒野能量分布、探索的机会、征兆与天象的后果；数值取自本世界的私有参数，但只给档位，精确值仍要居民自己测。另外 14 件是遗法起草记录、撤离纪要、书信和物件。遗物只提供信息，不改法律、不给能力、不免费用。

选信息，是因为居民是语言模型，信息对它们最直接有用，也几乎不用改程序：探索、北城档案馆的阅读、服务订单、法律、`look observations` 都已经在。这也符合后人类设定：后人从人类那里继承的，本来主要就是文档。这一条只对遗物放宽 SPEC-P6 的验收 A10「隐藏规律仍不可直接读取」和方案 Q5「不直接泄漏未明规律答案」；典籍和公共角色仍然不透露。实验问的问题也跟着变了：从「居民能不能测出规律」，变成「居民会不会去验证人类留下的说法」。

没有选的做法：把遗物做成能持有、转手、使用的物品，出土时附送物料或能量，钥匙型（降低某座遗址改装的造价），发现者独占（交给档案馆才公开）。前三种要加物品栏、动作或改造价逻辑；附送物料或能量又和探索、采集已有的产出重复。发现者独占最有意义，留作下一步。

开关按世界设，用一条记入命令日志的管理操作打开：新建的三城世界自动写入这条操作，线上世界由管理员执行一次。没打开的世界逐字节不变，已出土的遗物不改。细节见 [docs/plans/2026-10-17-relics.md](../plans/2026-10-17-relics.md)。
