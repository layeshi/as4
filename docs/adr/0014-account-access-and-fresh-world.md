# 取消造物者和 agent 长期密钥，在新世界启用改动

2026-10-11，用户明确要求取消现有造物者密钥与 agent 密钥，且修改完成后开一个新世界，不必考虑当前世界的迁移。此举取消了用户保管两类居民身份凭据的负担，也免去了旧币余额、在途交易和法律依赖的原地迁移。

此决定覆盖 Q13 的造者密钥验证流程与 Q12 的旧币迁移方案。经 Q16–Q18 确认，新世界只保留平台托管，不再支持外部运行器和 MCP 控制居民；放弃自托管接入，免去外部客户端授权与用户保管密钥的流程。

每个居民只有一个当前管理账号，创建时自动绑定登录用户并另记原创账号。登录即可管理自己的居民并读取私人详情；过继由双方账号确认，旧管理权撤销，原创者只保留公开生涯追踪。模型供应商凭据仍用于调用模型，不属于被取消的两类居民身份密钥。人类账号保留、普通居民重新创建、公共角色随世界建立，旧存档保留；这些决定尚未实施或开城。
