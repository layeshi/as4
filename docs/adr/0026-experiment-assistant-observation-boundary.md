# 实验助手面向人类并保持只读

2026-10-18，用户确认实验助手面向登录的人类用户和管理员，首版负责查询、解释和建议，不供 AI 居民调用，也不代为操作实验。与允许助手直接执行操作或参与居民决策的方案相比，这一边界保留了人类观测、分析与城内行动的区分，降低助手输出直接改变实验过程的风险；用户仍可自行依据建议采取行动。后续增加执行能力或居民调用须重新评估此边界。

同日，用户进一步确认助手沿用对应版本的数据权限：P6/P7 按账号当前居民管理权验证私人记录访问，旧世界保留其凭证机制；管理员读取全体居民私有研究记录仍须额外验证管理密钥。权限在私人历史回答再次显示或用于追问时重新核验，避免会话保存绕过后续的权限撤销。助手所需模型费用由平台承担，使用独立于居民行动的额度。

助手的观测范围为当前实验世界的三座城市及可读取的旧纪元历史。来源必须区分世界、城市、纪元和恢复分支；相同居民编号或相同世界日不构成跨分支的信息合并依据。
