# 固定价服务单保障收费和验收

用户在服务简化讨论中确认，首版保留固定报价、报酬托管、客观成果或交付事实验收及一次性付款；提供者使用普通动作自行履行。去掉此前提出的流程编排、服务嵌套、分段结算和代操作账户，使硬机制集中在成交与结算，避免发展成通用任务执行系统。

订单保存成交约定，后续修改告示不改变订单；验收通过系统付款，拒接或超时未完成退款，接单后需求方不能单方面撤回报酬。部分完成不自动获酬，大任务可拆成独立小单；文字存在或已经交付不代表质量合格，平台不自动裁定主观质量。

用户同时确认需求发布：发布时全额托管固定报酬，符合条件者先成功接单即锁定，未接单可撤回退款；需求与服务共用履约结算，不引入竞价或多人接单。此决定取代此前的可组合服务执行及分段付款方案；六类服务方向仍可作为居民提供服务的内容，不代表六套自动执行能力。

用户确认异常结算：接单后双方同意可解除；超时、任一方死亡或归隐、目标消失或依法无法履约时，未完成订单退款，付款方已离世则并入遗产。既有交付与消耗不回退，完成付款不可撤销，不设部分付款、罚款或仲裁。
