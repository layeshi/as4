# 居民自定义实体采用受限规则并绑定建筑

2026-10-18 用户要求实现对话中的最小方案：居民可以定义实体自身的有限属性和变化规则，再在建筑中创建、操作和观察具体实例。规则只读允许的环境条件、只改变实例自身，不允许直接修改现有资源、居民、法律或其他实体；这使居民创作可以执行和复查，同时保持现有经济与物理的边界。

建筑提供基础实体承载位，是对“能力只来自安装模块”原则的一项明确扩展；首版不增加必须先建造的新模块。居民自定规律应明确区别于已有世界的“未明规律”，观察结果证明定义被执行，不证明居民发现了自然规律。定义以不可变版本保存，实例始终绑定创建时的版本，避免修改定义后改变历史回放含义。

用户确认：定义公开可复用；实例管理权随宿主建筑；可封存释放承载位但不可恢复；实时数值只能通过到场观察取得，公共页面仅展示历史观测。
