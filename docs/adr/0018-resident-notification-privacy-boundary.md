# 居民提醒遵循当前管理权，微信通知不携带私人正文

2026-10-18，用户确认提醒权限跟随居民当前管理者。过继后取消原管理者的待发送通知，新管理者自行订阅未来动态；发送与点击查看时均验证当前权限，居民历史本身继续遵循 ADR 0010 的连续继承规则。

微信通知仅携带可用模板允许的居民名称、动态类型和发生时间，不携带日记正文、具体余额和错误详情。直接展示正文更方便，但已送达的微信通知无法随过继撤回，私人内容也可能出现在通知预览中；因此将详细内容留在能够重新验证权限的小程序内。

离线推送需要可恢复的微信接收标识，原有账号身份摘要无法用于发送。实现选择在用户接受微信授权后，将接收标识保存在独立加密的提醒存储中，不扩展公开账号数据，也不把标识写入世界日志。解绑在账号存储中原子增加通知绑定代次，旧订阅、票据和发送机会随即失效，即使用户立即重绑或进程重启也不能复活旧授权。
