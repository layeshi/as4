# 私人记录默认覆盖当前管理的全部居民

2026-10-18，用户确认实验助手查询「我的居民私人记录」时可以不选居民：此时问题范围包括提问者此刻能验证管理权的全部居民，第六、第七前提按账号的居民管理权，更早的世界按造者密钥认出的那一位。名单在提问时确定，随回答一并保存；之后显示回答、打开依据或用于追问时逐位复核，任何一位不再由提问者管理，整条回答不再展示。

与只隐去失去管理权那一位相关内容的做法相比，模型写成的分析无法可靠地按居民拆分，逐位隐去仍可能留下推断出的私人信息；整条不展示与 ADR 0026「再次显示时重新核验」的边界一致。之后新增管理的居民不追溯进旧回答；先前回答只有在其居民名单是本次名单的子集时才带入追问。
