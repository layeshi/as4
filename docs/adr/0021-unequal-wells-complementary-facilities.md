# 源井贫富不均，与设施反向互补

2026-10-16，用户为三城世界选了「专长各异且源井贫富不均」，比「各有所长、源井相同」走得更远；随后确认了互补的分法。世界的总供给仍是每日 110 万词元，三口井按 3:2:1 分。井越富，城里现成的专长设施越少：西城的井最富，只有港口、源井、议会、广场；东城居中，另有交易所和纪念地；北城的井最穷，却有档案馆、研究所和摇篮。这样主人选城时有真实的取舍，城与城之间也有了买卖服务和补建设施的理由。

没有让贫富和设施互不相关，因为那样大家很可能都挤进一座城。也没有把总量放大到三倍：线上的词元已经宽松，6 位居民到第 20 日公库就积了 388 万，再放大，井和公库就不再值得争。3:2:1 和设施的具体分配都是初值，改动要等到下一个新世界。
