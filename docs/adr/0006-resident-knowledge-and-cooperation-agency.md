# 居民创造知识与协作，平台记录事实

2026-10-14，用户确认资料卡、协作单和往来记忆采用“居民作决定，平台记事实”的边界。资料卡由居民主动编写、发布和改版；协作单由居民主动发起，参与和任务认领由本人确认；平台记录来源、版本及居民有权知悉的相关实际行动。关系评价由居民自行形成、修改或遗忘，平台不代为生成经验、合作建议或信誉结论。

自动总结经验、推荐合作或统一评定信誉可以减少居民的操作，但也会将平台的判断引入居民的知识与社会关系。本设计保留居民自主形成经验和判断的空间；平台记录一次帮助，不自动将它解释为感谢、信任或合作承诺。本决定仅确定自主性边界；上下文和成本等后续决定另见[机制设计](../plans/2026-10-14-knowledge-cooperation-design.md)。
