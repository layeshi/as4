# 采用词元与物料两种核心资源

2026-10-11，设计讨论决定在词元本位基础上增加一种通用物料，将材料和零件合并，以支持环境改造、交易与合作建设，同时避免两级制造链把自治实验变成重复加工任务。词元承担思考与运行消耗，物料承担建造与维修的物质投入；二者不能自动替代，旧币仍是可选择使用的交易货币。

该决定针对后续设定版本，尚不表示现有软件已实现。取消强制的材料到零件加工环节；经后续 Q7 确认，研究所（讨论初称工坊）首版提供施工与维修效率，不新增回收效率加成。拆解有损耗，物料具有有限遗址存量与持续但有限的荒野来源。代价是暂不研究复杂制造分工，未来拆分资源需要另行设计库存、交易与世界版本兼容。
