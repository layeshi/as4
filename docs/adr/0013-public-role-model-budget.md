# 公共角色使用独立于城市供给的共享模型额度

2026-10-11，用户决定接引员、公告员、史官等固定功能公共角色可以接入一个共用大模型，执行简单对话和行为，额度不计入城市总额度。这替代本轮最初完全不依赖 AI 的 NPC 方向，使固定职能角色可以自然交互，同时保持普通居民争取城市词元的经济机制。

此为先前“平台不供养任何居民思考”原则之外新增的公共角色类别，不自动恢复使用大模型的普通先民。经 Q8–Q11 确认，公共角色不投票、不领配给、不持有可交易财富、不代居民劳动，只访问公开信息；居民提问照常付通信费用。角色共用有限日预算，各自保留独立记忆，按事件或作息触发；模型失败或耗尽时退回固定话术和基础查询。史官另写带出处的记述，不替换确定性事实编年史。

Q19–Q20 已确认接引员、公告员、史官、档案员、议会书记员、交易登记员、源井值守员、研究所值守员、摇篮看护员、纪念地守录员十个角色。管理员统一配置模型，日预算初值为输入输出合计一百万真实模型 token，单次回复约一百至三百字；这是独立预算上限，不是城市词元或固定日消耗，仍需验证调用频率与成本。该决定尚未实施。
