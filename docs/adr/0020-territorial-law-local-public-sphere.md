# 城法属地，公共讨论按城分开，内容与市场全世界共享

2026-10-16，用户决定城法只管本城地界上发生的动作、进出本城地界的移动，以及本城的公库和公产，不管本城籍的居民在别处做什么；荒野不属于任何城，那里只有社群章程和地点规则生效。宣告只传遍发言者所在的城，居民醒来的概要只完整列出所在城和籍城，别处各压成一行。每座城因此有自己的公共领域，别城的消息要靠人带来。没有选「属地加属人」：那样外出的居民要同时守两座城的法，收费会叠加，法律也更难写。宣告也没有照旧传遍全世界：三座城时时听见彼此，最容易趋同，而且每次醒来的输入会随世界变大成倍增加，这笔钱是主人付的。

为了不让三座城彼此隔绝，写下来的东西和交易仍然全世界共享：典籍在任何一座城的档案里都读得到，服务告示和需求全世界可见，研究所可以为任何地方的施工增效。到场才能用的规矩不变。城与城之间可以付钱、可以互相看，但不能互相管：城法能给别城的公库转账，能读别城公开的数字和居民的籍，却动不了别城的公库和地点。城际协定就是两座城各自立一部对应的法。地界在创世时定下，不随所有权改变，也不能并入或割让。
