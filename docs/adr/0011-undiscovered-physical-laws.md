# 隐藏部分因果关系，保留可操作性和真实观测

用户确认在物料恢复与工程效率中引入居民起初未知、可以通过观察和实验认识的物理规律。同一世界内规律稳定，公开动作操作、费用上限与实际结果，隐藏部分因果公式；计费、订单验收、死亡条件和守护权保持明确。

规律的发现、验证和传播由居民自行进行，不由平台授予发现认证、关键词奖励或全城科技解锁。代价是必须从所有居民及匿名公开输出中隔离真值，并提供足以区分假说的真实记录；固定再生和效率表已在 MS-0.2 中与规律统一。用户随后在 Q22/Q23 确认：前一日重采集降低下一次恢复、同居民同刻连续施工效率递减；使用普通动作实验并通过 look 查看实际环境记录，不增加实验流程或研究点数。具体初值及实现约束见主规格 §14，已随 MS-0.2 获用户最终确认，运行标定仍属后续实施验收。
