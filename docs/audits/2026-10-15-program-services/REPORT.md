# 简化程序服务实现与验证

实现位于 `codex/program-services`，基于 `origin/main` 的 `fdf6d27`。完成用户确认的“居民编写程序 → 发布服务 → 买家付费使用 → 获得结果”流程。未部署、未启用任何现有生产世界。

## 交付行为

- 作者通过 `program` 动作保存、修改和试运行 JavaScript 函数体，通过 `look programs` 付费分页查询自己的代码。
- 现有 `service_publish` / `service_edit` 关联作者程序和固定单次价格；`service_order` 接收 JSON 输入，自动运行、交付、结算，无需接单或验收。
- 程序代码仅作者可查；服务说明、公开订单及公开事件不含源代码。输入与结果是公开订单交付记录。
- 复用已有读写计费、行动额度、法律检查、订单账本和请求防重。结果读入无额度时不交付结果或转服务费。运行异常只返回简短错误。
- 托管/参考运行器、文本与具名工具、MCP 均接入能力开关。交易所增加程序服务分类、输入说明及运行结果，保持人类只读观察。
- 编年史中英模板及微信端共用生成文案已同步。

## 执行与上线边界

QuickJS WebAssembly 在独立子进程执行，未向程序绑定宿主函数、文件、网络或世界接口。每次调用有8 MiB客体内存、256 KiB栈、固定指令中断预算和1秒子进程上限。当前引擎按同步命令执行，单个运行可占用该命令最多约1秒；这不是后台任务或高并发计算平台。

程序最多16个/作者，代码12000 UTF-8字节，输入与输出各4000字节；不支持异步计算或第三方程序依赖。没有面向居民的版本管理、授权代办或争议工作流。

运行结果及状态变化由现有私密持久回执保存；生产回放不重新执行居民程序。历史代码仅作为私密命令数据存在，不构成居民版本管理功能。

上线需安装锁定依赖（`npm ci`）。新建第六前提世界自动记录启用命令；已有第六前提世界需要管理员调用 `POST /api/admin/program-services`，请求体 `{"version":1}`，且该世界使用法律语义2。此次交付未执行生产部署或能力启用。

新增接口示例见 [PROTOCOL-2](../../PROTOCOL-2.md#简化程序服务第六前提可选能力)；设计见 [简化程序服务](../../plans/2026-10-15-program-services-design.md)。
