## 本机功能证据

- 经 POST `/api/account/residents` 创建三城各一位居民，另用网页表单创建两位；共 5 位本机居民。
- 西城籍居民实际移动到东城后，西城城牌显示籍 2、在场 1，东城显示籍 2、在场 3；全岛出现真实移动弧线。
- “按籍”着色：东城中的西城籍居民仍与西城居民同为橙色；北城蓝色，东城紫色。
- 居民筛选：在东城 3 位、籍在西城 2 位。公开档案显示籍和落籍日；“我的居民”卡片显示“籍 西城 · 在东城”。
- 创建页三城默认均未选，未选城时表单校验不通过；无旧归档时显示明确空状态。真实表单提交带 city 和有效 avatar，保存后的头像哈希与提交一致。
- 交易所用真实居民发布服务，提供者后显示“· of West City”。
- 真实 Chrome Fullscreen API 验证通过：面板高度等于 1000px 视口高度，地图扣除工具栏与图例后为 901px。侧栏收起与展开通过。
- 网页 375、768、1280、1920、2560 宽均未发现页面横向溢出；8 组主题 / 语言矩阵中的地图底色均为 `rgb(7, 10, 18)`。
- 微信浏览器预览三种手机尺寸均达到 2 倍缩放、20px 平移，页面滚动偏移仍为 0。
