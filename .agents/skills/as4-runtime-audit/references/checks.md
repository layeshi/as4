# 有证据的专项检查

根据用户关注点选读，不机械地运行全部测试。先确认实际部署版本包含哪些模块；以下路径是源码定位线索。

## 服务与运行器

- `src/runtime.js`：时钟、命令先写后执行、快照时机、恢复尾部日志。检查停顿是否为 paused、发布后的计时器重建、进程阻塞或模型未动作，不混为同一故障。
- `src/runner/manager.js`、`src/shells/manager.js`：居民 alive/awake 与运行器 enabled、in-flight、错误/暂停是不同状态；造者绑定、Agent令牌变化、运行器配置丢失必须分别查证。不打印加密材料或私有配置。
- `runner/providers.js`、`runner/agent.js`：供应商 HTTP 状态、finish reason、输入/输出/思考 token（如有），解析结果与实际动作。不能仅凭输出等于上限断言所有输出都是思考；预算、单次上限、超时和限流需分别核对。检查无效输出是否被错误记成可用行动。
- 比較同一时间窗内各线路成功/失败率及调用次数；“无调用”不是100%成功。累积用量与时区重置边界必须对应。
- 真实模型付费复测不属于默认只读巡检；优先历史自然运行日志，确需额外调用时给出具体目的和预计范围后确认。

## 信息反馈链

从实际请求跟踪完整路径：engine action result → HTTP/进程内客户端 → runner lastResults → 下一轮模型 messages。定位 `src/http/agent.js`、`src/action-feedback.js`、`runner/render.js`、`runner/render2.js`、`mcp/server.js`。

用隔离合成世界和 mock provider 连续两轮验证：draft内部失败是否被当成功、preview错误和错误路径是否送到模型、read正文是否保留、长文是否有未说明的截断。不能只测格式化函数返回了字符串。原始引擎ok、响应data.ok、静态校验和运行预览不是同一语义。

检查法律错误是否只是历史记录；有效法律不等于执行成功，历史失败也不等于当前仍然失败。已废止的法律不能被当作当前活跃故障。

## 经济与公库

定位 `src/e2/engine/economy.js`、`ledger.js`、`tick.js`、`rules.js`、`src/fiscal-view.js`。第一纪应切换到对应引擎，不能用第二纪口径解释。

1. 固定异常前后两个明确截点，列起止公库/居民余额、人口、有效法律和源井产出。
2. 按命令逐笔重放余额差，分解井产、居民捐赠、法律分发/津贴、维护、腐坏、遗产、项目/退款及其他实际出现的来源。事件不完整时不得用猜测补齐差额。
3. 表中验证“期初+全部收入−全部支出=期末”；差额未解释则明确列出。
4. 同时验证总能量、旧币守恒；守恒仍可能伴随双重配给、停发、分配不公。
5. 指标对照事件原始支出：share、each+transfer、部分兑付、多条规则、零居民、沉睡/死亡时间点及统计分母；注意旧版仅统计第一笔share的问题，不预设当前仍存在。
6. `rationPerCapita` 在新版观测层可能指全部日结法律拨款/日终在世人数，包含定期津贴，并非每位居民实际领取额。`legacyRationPerCapita` 是历史旧口径。总量、人均与逐人分配必须分开。
7. 公库上限可能是腐坏起算点，不是余额硬上限；腐坏整数取整和结算顺序会改变反事实差额。

预测只能在内存副本做，记录“不行动/不修法/固定规则”等假设；不能把推演当未来事实或让生产世界跟着推进。

## 游戏规则与设计

定位 `docs/PROTOCOL-2.md`、`docs/SPEC-E2.md` 与实际执行代码。分别判断：文字意图是否一致、是否合法、运行是否报错、结果是否符合政策目标。

- set在同一规则中的可见性、先收集后施行、失败时整条规则丢弃，不能按普通顺序脚本理解。
- 完好度基点0–10000与比例千分比0–1000；字段city前缀、账户treasury与余额city.treasury。
- basedOn、repeal、旧法与新法并行；不要仅凭标题“修订”推断替换成功。
- after:repair的目标和实际spent；当日累计投入不是累计补贴；需验证阈值边界与多次行为。
- 维护费导致停摆、before规则错误时是否放行、资源底线、部分兑付及按ID顺序转账的公平性。
- 保留金约束作用于哪条法律，是否被其他支出绕过；沉睡者资格、唤醒、去世继承、人口变化和空集合除零。
- 表决阈值与取整是否符合文字，程序更替和恢复路径是否存在。

2026-10-03旧审计可作为回归样例，见项目 `docs/audits/2026-10-03/`；它不是当前事实来源，不能据此宣布今天仍停发或仍有相同错误。
